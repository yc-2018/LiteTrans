# 轻译 LiteTrans

Windows 11 上的轻量翻译小工具。单个 exe 约 110 KB，常驻托盘，不装任何运行时。

![](https://img11.360buyimg.com/cxxjwimg/jfs/t1/513041/40/16863/172878/6aa898a7F6b54104a/06d776b2ede96648.webp)

## 快速开始

双击 `LiteTrans.exe` 即可。程序直接隐藏到托盘，不弹窗口。

| 操作 | 效果 |
| --- | --- |
| `Ctrl+Alt+D` | 翻译选中的文字（没选中就翻译剪贴板） |
| `Esc` | 收回托盘 |
| `Ctrl+Enter` | 翻译输入框里的内容 |
| `Ctrl+Shift+C` | 复制译文 |
| `Ctrl+D` | 朗读 |
| `Ctrl+Tab` | 在自动识别、固定目标、固定反向三种模式间切换 |
| `Ctrl+,` | 打开设置 |
| 左键单击托盘 | 弹出翻译窗口 |
| 右键单击托盘 | 菜单（含最近翻译、设置、退出） |

主窗口左上角的模式下拉框也可以直接选择自动识别、固定译成目标语言或固定译成反向语言。

## 划词翻译

**选中文字，直接按 `Ctrl+Alt+D`，不用先复制。**

程序用两条路径取词，自动选择：

1. **直接读取**选中文字 —— 不碰剪贴板、无按键副作用。浏览器、Office、记事本、
   IDE 等绝大多数程序都支持。
2. **模拟复制**：少数程序（部分 PDF 阅读器、终端、老式控件）不支持第 1 种，程序会**替你按一次
   `Ctrl+C`**，取完再把剪贴板还原成原来的内容。

如果某个程序取词失败，到「设置 → 常规 → 划词翻译」把**取词等待**调到 `400~600` 毫秒。
没有选中任何文字时，会自动退回翻译剪贴板里的内容。

## 翻译引擎

默认用**腾讯交互翻译**，免密钥、国内直连、无需任何配置。

查**单个英文单词**时会自动附带英美双音标和分词性释义，例如查 `persistent`：

```
英 [pəˈsɪstənt]   美 [pərˈsɪstənt]
持久性

词典释义
  adj.  （尤指不好或不受欢迎的状态或情况）持续存在的，继续发生的
  adj.  执著的；不屈不挠的；锲而不舍的
```

可选接入（设置 → 高级接口）：

- **AI 精翻**：可在「高级接口」中添加多个任意 OpenAI 兼容接口（通义千问、DeepSeek、Kimi、智谱、本地 Ollama 等），
  为每个接口自定义名称、地址、模型和提示词。接口地址填到 `/v1` 即可，程序自动补 `/chat/completions`。
- **百度翻译**：在 [开发者管理页](https://fanyi-api.baidu.com/manage/developer) 免费申请，填 APP ID 和密钥。

任一引擎失败都会自动回退到腾讯翻译，所以**始终可用**。设置页可分别测试每个 AI 配置、百度和首选引擎的连通性。
主窗口标题栏的「全部引擎」按钮可以并发请求腾讯、百度和所有已启用且配置完整的 AI 接口，并在译文区分别显示结果。

## 主要设置

设置分六页（托盘菜单 → 设置，或 `Ctrl+,`）：

- **常规**：快捷键自定义、开机自启、划词翻译、Esc 收回、失焦隐藏、置顶、复制即翻译
- **外观**：浅色 / 深色 / 跟随系统、主题色、字体、字号、不透明度、弹出位置（居中 / 鼠标旁 / 记住上次）
- **翻译**：目标语言与反向语言、自动判断方向、引擎、词典增强、剪贴板文本预处理；主窗口可快速切换翻译模式
- **朗读与历史**：自动朗读、语速音量、历史条数
- **高级接口**：多个 AI 配置（可自定义名称）、百度密钥、连通性测试

### 剪贴板文本预处理

从代码或 PDF 里复制的文字往往不适合直接翻译，程序会自动整理（可逐项关闭）：

- 驼峰拆词：`getUserName` → `get User Name`
- 下划线转空格、合并多余空白
- 接合排版换行：修复 PDF 复制出来的断行
- 去除行首的 `//` `#` `*` 等注释符号

## 开机自启

在「设置 → 常规 → 启动」中开启。写入的是当前用户的启动项
（`HKCU\...\Run`），**不需要管理员权限**，随时可关。

## 文件位置

- 配置：`%APPDATA%\LiteTrans\config.json`（可直接手改，格式化过便于阅读）
- 历史：`%APPDATA%\LiteTrans\history.json`
- 出错日志：`%APPDATA%\LiteTrans\crash.log`（仅异常时生成）

设置页「打开配置文件夹」可直达。

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| 无 | 按配置启动（默认隐藏到托盘） |
| `--tray` | 强制隐藏启动（开机自启用的就是这个） |
| `--show` | 启动就显示窗口 |
| `--settings` | 直接打开设置页 |

程序是单实例的：重复启动只会唤起已在运行的那个，不会开出第二份。

## 自行修改与编译

源码在 `src\`，双击 `build.cmd` 即可重新编译，只依赖 Windows 自带的 .NET Framework
编译器（`csc.exe`），**不需要装 Visual Studio 或任何 SDK**。

## GitHub 自动发布

仓库中的 `.github/workflows/release.yml` 会在推送 `v主版本.次版本.修订版本` 标签时运行 Windows 构建，
生成包含 `LiteTrans.exe`、`README.md` 和 `LICENSE` 的压缩包，并自动上传到 GitHub Release，同时附带 SHA-256 校验文件。
例如：

```text
git tag v1.0.0
git push origin v1.0.0
```

也可以在 GitHub Actions 页面手动运行工作流，并填写要创建或更新的版本标签。

## 托盘图标看不到？

Win11 默认把新程序的托盘图标收进溢出区。点任务栏的 `^` 展开即可看到，
想常驻显示就把它拖到通知区域，或在「任务栏设置 → 其他系统托盘图标」里打开。
